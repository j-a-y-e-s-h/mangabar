Frequently Asked Questions

Can I read manga offline with MangaBar?

Yes. MangaBar fully supports offline chapter downloads. Downloaded chapters are saved locally so you can read anytime without internet connectivity.

Does zooming manga affect my editor text zoom?

No. MangaBar implements clamped zoom event isolation (0.5x to 4.0x) so zooming pages never zooms your code font or IDE window.

Does MangaBar work in Cursor, Windsurf, or VSCodium?

Yes. MangaBar is fully compatible with any modern editor built on the VS Code engine (v1.85.0+).

Where are my downloads stored?

All data is stored locally in your profile at ~/.mangabar. You can also customize the directory anytime via VS Code settings.
