Frequently Asked Questions

Everything you need to know about MangaBar (Manga Bar) for VS Code & Cursor.

MangaBar (also searched as Manga Bar) is an open-source, offline-first manga, manhwa, and comic reader extension designed specifically for code editors such as VS Code, Cursor, Windsurf, and VSCodium. Read without context switching or breaking your development flow.
Install MangaBar directly from the VS Code Marketplace or load the .vsix in Cursor. Press Ctrl+Alt+M (Cmd+Alt+M on macOS) to open the reader sidebar, browse 350+ sources like MangaDex, and read directly inside your IDE.
Yes. MangaBar fully supports offline chapter downloads. Downloaded chapters are saved locally on disk in ~/.mangabar so you can read anytime without internet connectivity.
MangaBar supports over 350+ community extension sources via Keiyoushi, including MangaDex, ComicK, MangaKakalot, Asura Scans, Flame Comics, and dozens of localized language catalogs.
Yes! MangaBar is 100% free and open-source under the MIT license with zero telemetry, no tracking, and no ads. All your reading history and downloads remain completely private on your local disk.
No. MangaBar implements clamped zoom event isolation (0.5x to 4.0x) so zooming pages never zooms your code font or IDE window.
Yes. MangaBar is 100% compatible with any editor built on the modern VS Code core (v1.85.0+), including Cursor, Windsurf, VSCodium, and Positron.
